Cat Territory Practice Board

Cat Territory is our original browser puzzle in the Meowdoku style: one cat per coloured region, one per row and column, and no cats touching — not even diagonally. Every board is generated for this site and checked to have exactly one solution. It is a practice tool, not the official Meowdoku app.

How to play this board

  • Tap a cell to cycle: empty → ✕ (not a cat) → cat → empty.
  • Check validates the current cats and marks rule conflicts in red. The board also checks automatically when you place the last cat.
  • Hint reveals one correct cat from the solution and locks it. It clears any of your cats that would conflict with the revealed answer.
  • Clear marks removes your marks but keeps hinted cats.
  • Timer starts with each new puzzle; your best time per board size is stored in your browser.

What is generated, and how

Each puzzle starts from a valid solution — one cat per row and column, with no two cats adjacent. We then grow nine connected coloured regions around that solution, one cat per region, and run a solver that counts solutions. A board is only published if the solver finds exactly one solution. The same generator produced the diagrams on the rules and strategy pages.

Tips for using it as training

  1. Start on 6×6 and solve three boards without hints before moving up.
  2. Say the deduction out loud: “this region is confined to column 2, so column 2 is taken.”
  3. Use ✕ marks instead of guessing; the habit transfers directly to the app.
  4. When stuck, press Check rather than Hint. A conflict tells you which rule you misread.
  5. Once a size feels easy, move up rather than repeating the same board size for speed.
